# RALLY — ралли-игра с экранными кнопками (+ APK для Android)

Псевдо-3D раллийный спецучасток на `canvas`: гравий, лес, горы, пыль из-под колёс,
три стадии (день / закат / ночь с фарами) и рекорды по каждой в `localStorage`.

Один и тот же код работает в двух местах:

| Что | Файл | Как запустить |
| --- | --- | --- |
| Браузер (и живое превью) | `game/index.html` | открыть файл или `python3 -m http.server` в этой папке |
| Android-приложение | `dist/rally.apk` | установить на телефон (Android 5.0+) |

APK — это тот же `index.html` + `game.js` в `assets/www` внутри тонкой обёртки на
`WebView`. Ничего не грузится из сети: приложение полностью офлайновое.

## Управление

Экранные кнопки (всегда на экране, снизу):

```
   ◀   ▶            ТОРМОЗ   ГАЗ
  руль влево/вправо   педали
```

На компьютере: `←` `→` (или `A`/`D`) — руль, `↑`/`W` — газ, `↓`/`S` или `Space` —
тормоз, `Esc` — пауза, `R` — заново. Кнопки сделаны на `pointer`-событиях, поэтому
работают и мышью, и пальцем, и в мультитач (`газ` + `руль` одновременно).

## Как играть

- Три стадии: **СУ-1 Лесная гряда** (быстрый гравий), **СУ-2 Каменный хребет**
  (узкие повороты и перепады), **СУ-3 Ночная трасса** (фары, темнота).
- Отсчёт 3-2-1, потом таймер. На 1/3 и 2/3 дистанции — отсечки, на финише — арка
  и результат. Рекорд каждой стадии хранится отдельно.
- Съехал с дороги — скорость падает, машину трясёт, пыль столбом. На поворотах
  сносит наружу: перед шпилькой лучше сбросить газ.

## Сборка APK

Gradle и Android Studio не нужны — только четыре консольных инструмента.
Скрипт: [`build-apk.sh`](build-apk.sh).

```bash
cd rally
AAPT2=~/.tools/aapt2 \
ANDROID_JAR=~/.tools/android.jar \
D8_JAR=~/.tools/d8.jar \
APKSIGNER=~/.tools/apksigner.jar \
ECJ=~/.tools/ecj.jar \
JAVA=java \
./build-apk.sh
# -> dist/rally.apk (подписан v1+v2+v3, minSdk 21, targetSdk 34)
```

Откуда взять инструменты (все есть в публичных пакетах, ставить Android SDK не надо):

```bash
# aapt2 для linux x64
npm pack aaptjs3 && tar xzf aaptjs3-*.tgz && cp package/bin/x64/linux/aapt2 ~/.tools/

# android.jar (API 34), d8.jar, apksigner.jar, ecj.jar
npm pack @drxiaozhi/minapk && tar xzf drxiaozhi-minapk-*.tgz
cp package/tools/android.jar package/tools/d8.jar package/tools/apksigner.jar ~/.tools/
cp package/tools/ecj-3.45.0.jar ~/.tools/ecj.jar

# java/javac — подойдёт любой JDK 8+ (можно jdk4py из PyPI, если JDK нет)
pip install jdk4py
```

Что делает скрипт:

1. копирует `game/` в `build/assets/www`;
2. `aapt2 compile` + `aapt2 link` — ресурсы, бинарный манифест, `resources.arsc`, assets;
3. `ecj` (javac) → `.class`, `d8` → `classes.dex`;
4. `zip` добавляет `classes.dex` в APK;
5. `apksigner` подписывает ключом `android/rally.keystore` (создастся сам при первом
   запуске, пароль `rally2026`, alias `rally`).

> Ключ лежит в репозитории намеренно: без него новые версии нельзя ставить поверх
> старых (Android считает их разными приложениями). Для игрушки в интернете это
> нормально; для магазина приложений так делать нельзя.

## Структура

```
rally/
├── game/
│   ├── index.html      # разметка, CSS, HUD, экранные кнопки, оверлеи
│   └── game.js         # вся игра: трассы, физика, псевдо-3D рендер, звук
├── android/
│   ├── AndroidManifest.xml
│   ├── java/com/weebx/rally/MainActivity.java   # WebView на весь экран
│   └── res/                                     # строки, тема, иконки mipmap
├── build-apk.sh
├── dist/rally.apk      # готовый подписанный APK
└── index.html          # страница «играть / скачать»
```

## Как устроен рендер

Классический приём «Out Run»: трасса — массив сегментов по 200 условных единиц,
у каждого своя кривизна `curve` и высота `y`. Каждый кадр сегменты впереди
проецируются на экран (`scale = cameraDepth / z`), рисуются полосами снизу вверх,
дальние затухают туманом. Кривизна накапливается в смещении `dx` — так получаются
повороты; высота даёт горки и перекрытия (обрезка по `maxy`). Машина, деревья и
арка на финише — спрайты, нарисованные кодом, без картинок.

За производительность отвечают: `DRAW_DIST = 220`, обрезка по горизонту,
`devicePixelRatio` не выше 2 и запрет на кадры длиннее 1/20 с (после сворачивания
игра не «телепортирует» машину).

## Правки на скорую руку

- Сложность и длина стадии — массив `STAGES` в `game.js` (`targetSegments` — длина
  в сегментах, `curveScale` / `hillScale` — злость поворотов и горок).
- Цвета стадии — там же (`sky`, `grass`, `road`, `rumble`, `fog`).
- Скорость и физика — константы `MAX_SPEED`, `ACCEL`, `BRAKING`, `CENTRIFUGAL`.
